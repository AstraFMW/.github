## What is ASTRA?

ASTRA is a proprietary, full-stack FiveM roleplay framework engineered specifically for the ASTRA ecosystem.

Rather than building around a collection of disconnected community resources, ASTRA provides a unified foundation for player state, characters, inventory, jobs, vehicles, interfaces, administrative systems, and gameplay services through a shared `astra` interface.

The framework includes a middleware pipeline, bidirectional callbacks, native framework services, centralized state management, and an expanding collection of first-party systems designed to operate together as a single platform.

> **Private Framework** — ASTRA Framework and its first-party components are maintained exclusively for authorized ASTRA environments. Source code, internal resources, deployment tooling, and framework components are not intended for public distribution or unauthorized third-party deployment.

## Internal Framework Stack

| Resource | Purpose |
| --- | --- |
| `astra_core` | Framework runtime — shared `astra` interface, callbacks, middleware, state management, and core services |
| `astra_inventory` | Native slot-based inventory, item management, metadata, and player storage |
| `astra-characters` | Character lifecycle, identity, selection, and management |
| `astra-vehicles` | Vehicle ownership, garages, keys, and persistent vehicle state |
| `astra-hud` | Player HUD, notifications, progress interfaces, and client feedback |
| `astra-mdt` | Internal public-safety MDT and records infrastructure |
| `astra-jobs` | Employment framework — jobs, grades, duty management, and payroll |
| `astra-labor` | Civilian activities and side-work systems including fishing, farming, hunting, and other activities |

> Repository links are intentionally unavailable publicly. ASTRA's framework repositories are maintained privately and access is restricted to authorized development personnel.

## Internal Deployment

ASTRA environments are provisioned through an internally maintained deployment pipeline.

`ASTRA-TxRecipe` manages the base txAdmin deployment process and provides a consistent foundation for authorized development, testing, staging, and production environments.

Framework resources, dependencies, configuration, and supporting infrastructure are maintained through ASTRA-controlled repositories and deployment processes.

## Access

ASTRA Framework is not distributed as a general-purpose public FiveM framework.

Access to framework source code, internal repositories, development resources, deployment tooling, and documentation is limited to authorized ASTRA developers and approved personnel.

Possession of or access to ASTRA source code does not grant permission to redistribute, sublicense, republish, rebrand, sell, or deploy framework components outside authorized ASTRA environments.

Access to ASTRA repositories may be granted or revoked at the discretion of the ASTRA Framework team.

For applicable usage, modification, and distribution restrictions, refer to the license included with each ASTRA Framework repository.
