## What is ASTRA?

ASTRA is a privately developed, full-stack FiveM roleplay framework built specifically for the ASTRA ecosystem. It provides a middleware pipeline, bidirectional callbacks, native slot-based inventory, job systems, vehicle management, and a complete suite of integrated roleplay systems — all operating through a shared `astra` interface. Rather than relying on a collection of disconnected resources, ASTRA is engineered as a unified platform where first-party systems are designed, maintained, and deployed together.

> **Private Framework** — ASTRA Framework is maintained for authorized ASTRA environments and internal development. Framework components are not intended for general public deployment or third-party server distribution.

## Internal Framework Stack

| Resource | Purpose |
|----------|---------|
| [`astra_core`](https://github.com/AstraFMW/astra_core) | Internal framework foundation — shared `astra` interface, callbacks, middleware, and state |
| [`ox_inventory`](https://github.com/AstraFMW/ox_inventory) | Legacy inventory compatibility layer — production systems are transitioning to ASTRA's native `astra_inventory` implementation |
| [`astra-characters`](https://github.com/AstraFMW/astra-characters) | Character creation and management |
| [`astra-vehicles`](https://github.com/AstraFMW/astra-vehicles) | Vehicle ownership, garages, keys |
| [`astra-hud`](https://github.com/AstraFMW/astra-hud) | HUD, notifications, progress bars |
| [`astra-mdt`](https://github.com/AstraFMW/astra-mdt) | Police MDT |
| [`astra-jobs`](https://github.com/AstraFMW/astra-jobs) | Employment system — job/grade assignment, duty toggling, salary payout |
| [`astra-labor`](https://github.com/AstraFMW/astra-labor) | Side-gig gathering jobs — fishing, farming, hunting, and more, separate from `astra-jobs` |

<sub>Internal deployment: <a href="https://github.com/AstraFMW/ASTRA-TxRecipe">ASTRA-TxRecipe</a> provides the managed txAdmin deployment pipeline used to provision ASTRA framework environments.</sub>
