## ◈ What is ASTRA?

ASTRA is a proprietary, full-stack FiveM roleplay framework engineered specifically for the ASTRA ecosystem.

Rather than assembling a server from disconnected resources, ASTRA provides a unified foundation where first-party systems communicate through a shared `astra` interface.

The framework combines middleware, bidirectional callbacks, centralized state management, native framework services, and integrated gameplay systems into a single architecture designed around the needs of ASTRA.

> 🔒 **ASTRA Framework is privately maintained.** Source code, framework resources, deployment tooling, and internal repositories are available only to authorized ASTRA personnel and environments.

## ◈ Framework Architecture

| | Resource | Responsibility |
|:---:|---|---|
| ⚡ | **`astra_core`** | Shared `astra` interface, callbacks, middleware, state management, and framework services |
| 🎒 | **`astra_inventory`** | Native slot-based inventory, item metadata, storage, and item lifecycle |
| 👤 | **`astra-characters`** | Character creation, selection, identity, and lifecycle |
| 🚘 | **`astra-vehicles`** | Vehicle ownership, garages, keys, and persistent vehicle state |
| 🖥️ | **`astra-hud`** | HUD, notifications, progress interfaces, and player feedback |
| 🚔 | **`astra-mdt`** | Public-safety MDT and records infrastructure |
| 💼 | **`astra-jobs`** | Employment, grades, duty management, and payroll |
| ⛏️ | **`astra-labor`** | Civilian activities, gathering systems, and side-work |

<div align="center">

`astra_core` → `framework services` → `first-party resources` → `gameplay`

</div>

## 🚀 Deployment

ASTRA environments are provisioned through an internally maintained deployment pipeline.

### `ASTRA-TxRecipe`

The framework's txAdmin recipe provides a consistent foundation across development, testing, staging, and production environments.

<div align="center">

**DEVELOPMENT** → **TESTING** → **STAGING** → **PRODUCTION**

</div>

Framework resources, dependencies, and environment configuration are maintained through ASTRA-controlled infrastructure throughout the deployment lifecycle.
